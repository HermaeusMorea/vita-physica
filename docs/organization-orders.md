# 组织阶与低阶实验世界

这份笔记记录 Vita Physica 中关于组织阶的一个核心觉察：

```text
O_n 的法则，不应该直接从 O0 的原始状态中硬读出来；
它应该从 O_{n-1} 世界中的可控组合里被读出。
```

换句话说：

```text
每一阶从下一阶的运行中读出自己的法则。
每一阶又成为上一阶读取法则的实验世界。
```

## 为什么不是直接从 O0 读出一切

底层世界是可信的 substrate。它拥有实际运行的状态、规则和历史。

但如果每一个高阶对象和高阶法则都直接从底层 cell soup 中寻找，搜索空间会很快
爆炸。底层状态虽然有限，但它缺少高阶边界：系统很难直接知道哪些局部结构应该
被看成一个对象，哪些对象组合应该被看成一个更大的整体，哪些变化只是噪音，
哪些变化意味着新的法则。

所以 O0 是最终 grounding，但不应该是所有发现过程的唯一工作空间。

更合理的方式是分层读出：

```text
O1 从 O0 的运行中读出。
O2 从 O1 的运行中读出。
O3 从 O2 的运行中读出。
O4 从 O3 的运行中读出。
```

每一阶都继承下阶的可信性，但也获得自己的对象边界、实验变量和组合方式。

## O_{n-1} 是 O_n 的实验世界

当 O_{n-1} 已经有了稳定对象类型、状态变量和局部法则，它就不再只是证据来源。
它变成了 O_n 的实验世界。

在这个世界里，系统可以控制低阶对象的组合：

```text
选择组件
改变数量
改变相位
改变距离
改变方向
改变边界条件
引入扰动
重复运行
比较结果
记录异常
```

这些操作让高阶候选对象变得可研究。高阶法则不是从混沌中凭空抽出，而是在低一阶
已经可操作的对象世界中，通过构造、扰动、复现和比较逐渐显现。

一句话：

```text
O_{n-1} 不只是 O_n 的材料。
O_{n-1} 是 O_n 被发现的实验台。
```

## 组织阶的递归关系

一个组织阶可以被理解为某一尺度下的完整对象世界。

每一阶都有：

```text
object types
state variables
relations
interactions
composition rules
laws
validity conditions
failure modes
```

更高阶对象由低阶对象组成。但更高阶不是简单地把低阶对象堆在一起，而是发现某些
低阶组合本身具有稳定身份、状态和行为。

因此，组织阶之间的关系不是覆盖，而是递归生成：

```text
低阶对象的可控组合
-> 稳定的高阶候选
-> 高阶对象类型
-> 高阶法则
-> 新的实验世界
```

当一阶足够稳定，它就成为更高一阶的 substrate。

## 类生命游戏中的例子

在一个类生命游戏宇宙里，可以想象这样的递归：

```text
O0: cells
  对象是单个 cell。
  法则是 birth / survival / death。

O1: local forms
  对象是局部 cell configuration。
  法则从 cell dynamics 中读出。

O2: stable bodies
  对象是 still life、oscillator、glider、spaceship。
  法则从 O1 的形态变化、相位循环和身份保持中读出。

O3: assemblies
  对象是多个 stable bodies 的可复现组合。
  法则从 O2 对象的相位、方向、距离和碰撞结果中读出。

O4: systems
  对象是 gun network、signal channel、logic gate、memory loop 等功能系统。
  法则从 O3 组合体的时序、连接和稳定运行中读出。
```

这里的重点不是这些名字本身。它们只是早期直觉。真正重要的是：每一阶都有自己的
对象和法则，每一阶又为下一阶提供可控的实验世界。

## 验证方式的变化

这个觉察也改变了验证的理解。

底层 O0 的小窗口状态可以做有限枚举。但高阶 O_n 的完整状态空间通常不适合直接
枚举。高阶世界里会出现对象数量、相位、距离、边界、连接方式、环境扰动等许多
自由度，完整枚举会变得不自然，也很快爆炸。

所以高阶验证不应该主要是：

```text
枚举所有 O_n 状态
```

而应该是：

```text
把 O_n 的候选法则转化成 O_{n-1} 世界中的可控实验。
```

例如，一条高阶法则可以被验证为：

```text
构造满足前提的 O_{n-1} 组合
运行 O_{n-1} 动力学
投影结果到 O_n
检查是否符合 O_n 的候选法则
记录通过、失败和 anomaly
```

也就是说，O_n 的验证发生在 O_{n-1} 的实验世界里，并通过已经建立的 grounding
chain 最终连回 O0。

## 对交互的含义

这让玩家和 agent 的角色更清楚。

他们不是只在底层随机拨动 cell，也不是在高层凭空命名对象。他们是在某一组织阶
中制造可控组合，观察这些组合是否会稳定成更高阶对象。

玩家可以在 O_{n-1} 中做实验：

```text
摆放低阶对象
固定某些条件
改变一个变量
运行一段历史
观察是否出现稳定高阶结构
要求 agent 提出命名和法则
要求 verifier 寻找反例
```

因此，Vita Physica 的发现循环可以更精确地写成：

```text
在 O_{n-1} 中构造可控组合
-> 运行低阶世界
-> 观察稳定高阶现象
-> 提出 O_n 对象和法则
-> 在 O_{n-1} 中验证
-> 安装进 O_n
-> O_n 成为 O_{n+1} 的实验世界
```

这就是组织阶的核心生命力：世界不是一次性被理解的，而是逐阶获得自己的对象、
实验和法则。
