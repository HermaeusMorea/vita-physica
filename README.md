# Vita Physica

Vita Physica is a running universe whose inhabitants learn to name its physics.

Vita Physica 是一个持续运行的宇宙；它的居民学习命名自己的物理学。

它首先不是一个关于控制生命的游戏，而是一个关于观看世界如何先于理解而运行、
又如何在观察、命名和验证中逐渐长出语言、对象和法则的系统。

## 核心直觉

世界先运行。

理解随后发生。

Vita Physica 从一个拥有自身底层动力学的宇宙开始。系统不需要一开始就知道
哪些高层对象重要。它只需要一个会演化、会留下历史、可以被观察的 substrate。

agent 和玩家不是从定义世界意义的神的位置出发，而是作为运行宇宙之内或旁边的
观察者出发。他们要做的是注意规律，给规律命名，测试规律，并慢慢建立一套关于
这个已经在运动的世界的物理学。

所以 Vita Physica 的核心反转是：

```text
不是：agent 控制世界
而是：世界运行，agent 学习读取它
```

## 运行中的宇宙

最底层是 kernel reality：宇宙的实际状态、状态演化所遵循的规则，以及演化留下
的历史。

这一层本身不是语义性的。它不需要理解对象、意图、信号或法则。它只是按照已经
安装的底层物理推进现实。

更高层的意义必须在它之上被获得。

这里有一个重要区分：改变宇宙的状态，和改变宇宙的物理，并不是同一件事。状态
干预可以是普通实验的一部分：创造一个 pattern，扰动一片区域，设置一次碰撞，
或者重置某个初始条件。改变底层动力学则是更深的事件。它意味着一个不同的宇宙，
或者同一个项目中的一个新 epoch。

## 从 Pattern 到 Physics

高层对象不是预先假设好的。

它们从世界历史中的重复结构开始。一个局部形状再次出现。一个配置持续存在。
某个东西在保持身份的同时移动。某个东西周期性地回到自身。某个东西发射出其他
结构。某些东西碰撞、湮灭、转化。

一开始，这些都只是观察。然后它们可能成为候选概念。之后它们可能得到名字。
如果它们继续经受实验和验证，它们就可以成为系统语义物理中的稳定对象类型。

大致的过程是：

```text
raw state
-> recurring structure
-> named candidate
-> verified object type
-> usable semantic object
```

对象类型不是 kernel 中的新 primitive。底层世界仍然按照自己的规则运行。但当
一个对象类型被学会之后，同一个世界就可以在更高层被读取。

宇宙没有改变自己的 substrate。它获得了描述那些已经在发生之事的语言。

## 组织阶

世界不是只在一个尺度上存在。

一个 cell 是对象；许多 cell 组成的局部形态也可以是对象；许多局部形态组成
的稳定体也可以是对象；许多稳定体组成的阵列、机器或生态仍然可以是对象。

Vita Physica 把这种尺度上的组织称为 **组织阶**（organization order）。
组织阶不是 UI 层，也不是简单的显示方式。它是世界在某一尺度上形成可读对象
和可验证法则的方式。

每一个组织阶都有自己的小世界：

```text
object types
state variables
relations
interactions
composition rules
laws
validity conditions
failure modes
```

更高的组织阶由更低的组织阶构成，但不会取代它。cell 层仍然真实运行；高层
对象只是让许多低层事件在一个更大的尺度上变得可读、可追踪、可预测。

在系统内部，组织阶可以用 `O0, O1, O2...` 标识。它们的语义别名不需要一开始
就固定，而可以随着宇宙自身的发现逐渐出现：

```text
O0: substrate / cells
O1: local forms
O2: stable bodies
O3: assemblies
O4: systems
```

这些名字只是早期直觉，不是永久分类。真正重要的是：每一阶都可以拥有自己的
对象、交互和法则；当一阶足够稳定，它又会成为更高组织阶的 substrate。

把对象类型和法则安装进组织阶，不是重写现实。它是把一种经过验证的语义组织
方式纳入系统，用来读取现实。

当一个移动 pattern 成为被识别的对象时，系统看到的不再只是低层状态序列。它
也可以看到一个拥有身份、位置、相位、方向和预期行为的东西。这个对象在语义上
存在，因为系统已经学会了如何识别它、测试它，并把它纳入某个组织阶。

## 法则与验证

名字还不够。

一条被提出的法则，在经受世界检验之前，只是 candidate。

agent 和玩家可以提出 pattern、对象、分类和法则。但一个 proposal 不会仅仅
因为听起来合理或漂亮，就成为系统语义物理的一部分。它必须接受底层历史和动力学
的检查。

验证可以从很弱的形式开始。一条法则最初可能只由样本、实验和有界检查支持。
随着时间推移，更强的证据或证明方法可以进一步提升它的地位。

失败不只是拒绝。失败也是科学信息。

一个 anomaly 可能说明：某条法则需要更精确的适用条件；某个对象类型太粗；
某种 interaction 还没有被理解；或者一个新的组织阶正在等待被发现。

## 交互

玩家不只是被动观看。

交互可以是实验性的。玩家可以选择值得关注的区域，标记一段历史，询问什么东西
反复出现，设置碰撞，扰动状态，保存有趣配置，或者邀请 agent 提出名字和法则。

重要边界是：普通交互不应该悄悄重写物理。它应该创造证据，而不是抹掉世界。

这个系统中的活循环是：

```text
宇宙运行
-> 观察者注意到结构
-> 候选对象被命名
-> 实验被制造
-> 法则被测试
-> 对象和法则被安装进某个组织阶
-> 更高组织阶暴露出新的现象
```

游戏的目标不是命令每一个 cell。游戏的目标是帮助一个世界变得能被自己读懂。

## 为什么重要

Vita Physica 关心的是语义物理的诞生。

它追问：如果一个运行中的世界旁边有一群能够命名、测试、记忆和修正自己观察的
观察者，会发生什么？它把理解看成一种通过实验生长出来的东西，而不是放在现实
之上的静态描述。

这个项目活在类生命动力学和类语言意义之间的缝隙里：

```text
physics makes the world run
semantics makes the world readable
verification lets semantics enter the world without replacing physics
```

Vita Physica 是一个正在学习说出自己是什么的宇宙。
